# Excel Learning

## **Introduction**

This repository documents my **Microsoft Excel learning journey**, covering data preparation, cleaning, analysis, visualization, formulas, PivotTables, Power Query, Power Pivot, Data Modeling, DAX, and interactive dashboard development. The concepts have been learned through structured courses and reinforced through practical business-oriented data analysis situations and end-to-end Excel dashboard projects.

The repository includes learning from both **Microsoft Excel – Beginner to Advanced | 2024–2026 + AI** and **Complete Excel Tutorial for Data Analysis**, along with the Excel projects created by applying the concepts covered throughout these courses.

## **Applied Dashboard Project**

The concepts learned through the course were applied to a **Call Centre Performance Dashboard** project.

### **Call Centre Performance Dashboard**

Focus: Call centre operations, representative performance, purchase amounts, call duration, customer satisfaction, call trends, customer demographics, and representative-level analysis.

The project incorporated:

- **Excel Data Model** connecting Calls and Customers data through Customer ID
- **Power Pivot & DAX measures** for call count, purchase amount, call duration, average rating, and five-star calls
- **PivotTables & PivotCharts** for analytical reporting
- **Slicers & Report Connections** for interactive representative-level analysis
- Monthly and day-of-week call trend analysis
- Satisfaction rating distribution
- Male vs. female caller analysis by city
- Calls and purchase amount comparisons by representative
- Customer-level purchase amount analysis with data bars
- Conditional formatting for selected representative analysis
- **XLOOKUP** for dynamic representative details and images
- **RANK.AVG** for representative performance rankings
- Dynamic dashboard elements that update when different representatives are selected
- Refreshable analysis for newly added call data
